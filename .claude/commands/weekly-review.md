---
description: The Monday project review, written from three commands. The payment clock, the money position, the compliance state, then the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Nothing else goes in.

```
npm run construction -- attention
npm run construction -- margin
npm run construction -- compliance
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Work in hand, forecast margin, owed to us, subcontractor claims waiting on a schedule.
2. **The clock.** Every payment schedule due or missed and every delay notice due or late, by name and date. Empty is the system working.
3. **The money in.** Overdue progress claims, claims scheduled short and why, variations instructed and not submitted.
4. **The money out.** Cost lines over or near, with the cause named.
5. **The design team.** Overdue RFIs and late submittals, and which of them hold work.
6. **Site.** Uninsured subcontractors, overdue defects, quiet diaries.
7. **The five things to do this week**, picked from the attention list, and why each made it.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view` if the operator wants pages for the meeting: same numbers, the company's brand, and they print. Numbers come from the commands; if a number is not in the output, it does not go in the review.
